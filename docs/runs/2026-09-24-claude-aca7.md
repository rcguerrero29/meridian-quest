## Files

- `test/authors.js` — new. Fails on any commit whose author, committer or message carries an address that is not a no-reply one (GitHub's per-account and bot no-reply, GitHub's own, Claude's; RFC 2606 example domains), and on any such address in a file git could ship. Names a domain, never an address, because CI logs are public. `--hook` mode refuses a `git push` before it runs. It also fails any script under `test/`, `.github/` or `scripts/` that asks git for a name or an address. `--selftest`: 36 cases, fixtures built at run time so the file holds no address of its own.
- `.claude/settings.json` — new. A `PreToolUse` hook on Bash that runs `test/authors.js --hook`: anything but a push passes; a push that would publish a personal address is refused on the machine, before it is public — which CI cannot do.
- `.github/workflows/ci.yml` — the self-test joins the guards' red cases; a step in `smoke` (required) checks the commits a PR or push brings and every shippable file.
- `test/runs.js` — stops asking git for a name or address. It printed the owner's full name and a personal address in a NOTE eleven times on every CI run from 2026-09-23 (found by Zeni). It now prints the hash only; its answer (an agent's trailer or not) is unchanged.
- `docs/BOUNDARY.md` — the fifth line in the header; row 13½, the envelope (Zeni's text, checked against git); list rows. `docs/POSTMORTEM.md` — four entries, and what each cost.
- `docs/ASKS.md`, `docs/NEXT-SESSION.md` — his words, and the corrected date the exposure began.
